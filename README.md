# Smart Attendance System Using Bluetooth

# Blu-Mark

**Blu-Mark** is a smart attendance system built using Flutter, Firebase, and Bluetooth Low Energy (BLE).

It allows teachers to start a live attendance session, and students nearby are automatically marked present using Bluetooth proximity.

The system reduces proxy attendance and eliminates the need for manual roll calls or QR scanning.

The app includes separate teacher and student modules with real-time session management, secure authentication, and cloud-based attendance storage.
